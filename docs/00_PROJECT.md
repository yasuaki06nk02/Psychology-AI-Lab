# Psychology AI Lab

Version: 0.1.0

Status: Draft

---

# Purpose

Psychology AI Lab is an AI-native research and evaluation platform designed to objectively measure, compare, and improve the counseling capabilities of Large Language Models (LLMs).

Unlike end-user applications such as AIMindary, Psychology AI Lab is not intended to provide counseling directly to users.

Its purpose is to provide a reproducible research environment where AI models, prompts, knowledge bases, RAG configurations, and counseling strategies can be evaluated using standardized psychological benchmarks.

The platform serves as the development environment for creating validated counseling packages that can later be deployed to AIMindary or other AI counseling applications.

---

# Vision

Create the world's most reliable and extensible research platform for AI-assisted psychological counseling.

The platform aims to establish evidence-based methods for evaluating counseling quality rather than relying on subjective impressions.

Every improvement should be measurable, reproducible, and explainable.

---

# Goals

The primary goals of Psychology AI Lab are:

* Benchmark multiple AI models using identical psychological datasets.
* Establish objective evaluation metrics for AI counseling quality.
* Measure the impact of RAG on counseling performance.
* Evaluate prompt engineering strategies.
* Evaluate counselor personas.
* Evaluate psychological knowledge sources.
* Produce reproducible benchmark results.
* Generate reusable counseling packages for deployment.
* Continuously improve AI counseling through experimentation.

---

# Scope

Version 1 focuses only on benchmarking base AI models.

Included:

* AI Model Management
* Benchmark Dataset Management
* Benchmark Execution
* Score Calculation
* Benchmark Dashboard
* Experiment History
* Result Export

Excluded:

* RAG
* Vector Database
* Persona Optimization
* Prompt Optimization
* AIMindary Integration
* Voice Interaction
* Memory Engine

These features will be introduced in later versions.

---

# Product Principles

The platform follows these principles.

## Evidence First

Every improvement must be supported by measurable benchmark results.

Assumptions are never sufficient.

---

## Reproducibility

Every benchmark should be repeatable using the same model version, dataset version, configuration, and evaluation criteria.

---

## Modularity

Every major capability should exist as an independent component with clearly defined responsibilities.

Modules should be replaceable without affecting unrelated components.

---

## AI-Native Development

The project documentation is written primarily for AI-assisted software development.

The specification should contain enough information for coding agents such as Claude Code, Codex, Gemini CLI, and similar tools to implement the system with minimal ambiguity.

---

## Research Before Product

Psychology AI Lab exists to improve AI counseling systems.

Applications such as AIMindary consume validated outputs generated by this platform.

The research platform itself should remain independent from any single application.

# Relationship with AIMindary

Psychology AI Lab and AIMindary have different responsibilities.

Psychology AI Lab is responsible for:

* Research
* Benchmarking
* Evaluation
* Experimentation
* Optimization
* Package Generation

AIMindary is responsible for:

* Counseling
* User Interaction
* Daily Reflection
* Insight Generation
* Memory Management
* Voice Interaction

AIMindary should consume only validated packages produced by Psychology AI Lab.

This separation ensures that research and production remain independent.

---

# Project Philosophy

Psychology AI Lab is founded on one central idea:

> Every improvement to AI counseling should be measurable.

The platform should transform AI counseling development from intuition-driven experimentation into an evidence-based engineering process.

Rather than asking,

"Which model feels better?"

the platform should answer,

"Which model performs better, under which conditions, and by how much?"

This philosophy defines the foundation of the entire project.
