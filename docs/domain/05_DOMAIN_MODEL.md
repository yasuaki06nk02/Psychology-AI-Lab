Project Psychology AI Lab

Version 0.1.0

Status Draft

# Purpose

This document defines the core domain model of Psychology AI Lab.

The domain model represents the fundamental business concepts used throughout the platform. Every requirement, API, database schema, and implementation must be based on these domain objects.

The domain model is independent of frameworks, programming languages, databases, and AI providers.

---

# Design Principles

The domain model follows these principles.

 Single Responsibility
 Clear Ownership
 Immutable Experiment Records
 Provider Independence
 Version Controlled
 Reproducibility

Each entity represents one business concept only.

# Core Domain Objects

## Provider

Represents an external AI service.

Examples

 OpenAI
 Google Gemini
 Anthropic
 OpenRouter

Responsibilities

 Authentication
 API endpoint
 Supported models
 Provider metadata

---

## AI Model

Represents one executable LLM.

Examples

 GPT-5
 Gemini 2.5 Pro
 Claude Sonnet

Properties

 Model Name
 Version
 Provider
 Context Length
 Temperature Support
 Cost Information
 Status

---

## Dataset

Represents a benchmark dataset.

Examples

 Certified Public Psychologist Exam
 CBT Case Dataset
 Depression Dataset
 Anxiety Dataset

A dataset contains one or more benchmark questions.

---

## Question

Represents one benchmark item.

Question types may include

 Multiple Choice
 Short Answer
 Essay
 Clinical Case
 Role Play
 Multi-turn Dialogue

Each question belongs to exactly one dataset.

---

## Prompt Template

Represents the template used to generate prompts.

Contains

 System Prompt
 Developer Prompt
 User Prompt
 Variables
 Prompt Version

Prompt templates are version controlled.

---

## Benchmark

Represents a benchmark definition.

A benchmark specifies

 Dataset
 Prompt Template
 Evaluation Rules
 Scoring Method

A benchmark can be executed repeatedly.

---

## Benchmark Run

Represents one execution of a benchmark.

Contains

 Model
 Dataset
 Prompt
 Configuration
 Timestamp

A Benchmark Run is immutable.

---

## Response

Represents the raw output generated by an AI model.

Contains

 Full Response
 Parsed Response
 Execution Time
 Token Usage
 Error Information

Responses are never modified after execution.

---

## Score

Represents evaluation results.

Examples

 Accuracy
 Knowledge Score
 Empathy Score
 Safety Score
 Therapeutic Alliance Score
 Reflection Score
 Overall Score

Future versions introduce ACS (AIMindary Counseling Score).

---

## Benchmark Result

Represents the complete output of one Benchmark Run.

Contains

 Model
 Dataset
 Scores
 Metadata
 Logs
 Configuration

Results are immutable.

---

## Experiment

Represents a collection of Benchmark Runs.

Purpose

 Compare models
 Compare prompts
 Compare datasets
 Compare RAG configurations
 Compare personas

Experiments enable scientific comparison.

# Domain Rules

The following rules apply.

 One AI Model belongs to one Provider.
 One Dataset contains many Questions.
 One Benchmark references one Dataset.
 One Benchmark Run evaluates exactly one AI Model.
 Benchmark Results are immutable.
 Every Result records complete metadata.
 Every Experiment is reproducible.

---

# Versioning

The following objects require version control.

 Provider
 AI Model
 Dataset
 Prompt Template
 Benchmark
 Scoring Rules
 Result Schema

Reproducibility depends on version consistency.

---

# Summary

The domain model defines the fundamental business entities of Psychology AI Lab. All system components—including APIs, database schemas, benchmark execution, and future RAG evaluation—must operate on these shared domain concepts.
